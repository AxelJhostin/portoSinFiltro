Señales de ingeniería

Lo que diferencia “hacer una app” de construir un sistema

JIRA

Backlog trazable

Cada entrega vive en Jira (SCRUM-*). Objetivo, estado y responsable visibles.

STACK

Arquitectura en capas

UI → API → Postgres. El frontend no escribe directo a la BD: permisos en el backend.

CI

Calidad automatizada

Vitest + CI en GitHub Actions. Rate limit verificado con script de carga (429).

SQL

Datos versionados

BDD.sql / schema.sql + migraciones. Estado comunitario calculado en la vista SQL.

SHIP

Entrega en producción

Deploy en Vercel, CORS multi-origen, PWA y demo con checklist.

TEAM

Trabajo en equipo

Módulos M1–M4: BD, API, experiencia ciudadana, gestión y documentación.
